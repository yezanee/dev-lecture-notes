# 섹션 6: 스프링이 지원하는 프록시

---

## 프록시 팩토리 (ProxyFactory)

스프링이 제공하는 추상화 계층. 인터페이스가 있으면 JDK 동적 프록시, 구체 클래스만 있으면 CGLIB 자동 선택.

> **비유**: 자동차 공장. "세단 만들어줘" 하면 세단, "SUV 만들어줘" 하면 SUV를 만들어주는 것처럼, "이 객체에 프록시 씌워줘" 하면 인터페이스 유무에 따라 적절한 프록시를 알아서 만들어줌.

## Advice (어드바이스)

**핵심**: 개발자는 `InvocationHandler`나 `MethodInterceptor`를 직접 구현하지 않고 **Advice 하나만 만들면 됨**.

```java
public class TimeAdvice implements MethodInterceptor {
    @Override
    public Object invoke(MethodInvocation invocation) throws Throwable {
        long startTime = System.currentTimeMillis();
        Object result = invocation.proceed(); // target 호출
        long endTime = System.currentTimeMillis();
        log.info("TimeProxy 종료 resultTime={}", endTime - startTime);
        return result;
    }
}
```

> **비유**: "부가 기능을 뭘 할 건지"만 적으면 됨. 어떤 기술로 프록시를 만들든 스프링이 알아서 연결.

## 포인트컷, 어드바이스, 어드바이저

| 용어 | 역할 | 비유 |
|------|------|------|
| **포인트컷 (Pointcut)** | 어디에 부가 기능을 적용할지 필터링 (클래스/메서드명 기반) | 네비게이션 (목적지 설정) |
| **어드바이스 (Advice)** | 프록시가 호출하는 부가 기능 로직 | 실제 할 일 (로그, 시간측정 등) |
| **어드바이저 (Advisor)** | 포인트컷 1개 + 어드바이스 1개의 결합 | "이 장소에서 이 일을 해라" 지시서 |

```java
// 어드바이저 사용: "save, order로 시작하는 메서드에만 시간측정을 적용해라"
NameMatchMethodPointcut pointcut = new NameMatchMethodPointcut();
pointcut.setMappedNames("request*", "order*", "save*");

DefaultPointcutAdvisor advisor = new DefaultPointcutAdvisor(pointcut, new TimeAdvice());

ProxyFactory proxyFactory = new ProxyFactory(target);
proxyFactory.addAdvisor(advisor);
Object proxy = proxyFactory.getProxy();
```
