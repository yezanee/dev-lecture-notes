# 섹션 11: 다음으로

## 강의 전체 요약

이 강의에서 학습한 **스프링 부트 핵심 기능 5가지**를 정리한다:

### 1. 내장 WAS (섹션 2~3)
- 톰캣 같은 WAS를 내장하여 **별도 설치 없이** 실행 가능
- JAR 하나로 빌드 → 실행 (Executable Jar)
- `main()` 메서드 실행만으로 웹 서버 기동

### 2. 라이브러리 관리 (섹션 4)
- **스프링 부트 스타터**: 관련 라이브러리를 모아둔 세트 제공
- **버전 자동 관리**: `io.spring.dependency-management` 플러그인이 BOM 기반으로 호환되는 버전을 자동 선택

### 3. 자동 구성 (섹션 5)
- `@AutoConfiguration` + `@ConditionalOnXxx` 조합으로 필요한 빈을 자동 등록
- `@SpringBootApplication` → `@EnableAutoConfiguration` → `ImportSelector`로 동적 설정 로딩
- 개발자가 직접 빈을 등록하면 자동 구성보다 우선 적용

### 4. 외부 설정과 프로필 (섹션 6~7)
- `Environment` + `PropertySource` 추상화로 **일관된 외부 설정 조회**
- `@Value`로 간편한 값 주입
- `@ConfigurationProperties`로 **타입 안전한 설정 속성** (검증 포함)
- `@Profile`로 환경별 빈 등록

### 5. 프로덕션 준비 — 모니터링 (섹션 8~10)
- **액츄에이터**: 헬스 체크, 로그 레벨 변경, 메트릭 제공
- **마이크로미터**: 메트릭 추상화 (모니터링 툴에 독립적)
- **프로메테우스 + 그라파나**: 메트릭 수집/저장 + 대시보드
- 커스텀 메트릭: Counter, Timer, Gauge

## 다음 학습 방향

스프링 부트의 핵심 원리를 이해했으니, 다음 단계로:

4. 필요한 경우 **자동 구성을 직접 만들어** 라이브러리로 제공해보기
