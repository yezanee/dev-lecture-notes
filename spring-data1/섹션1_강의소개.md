# 섹션 1: 강의 소개

## 강의 목표

스프링이 제공하는 **데이터 접근 기술의 핵심 원리**를 이해하는 것이 목표이다.

이 강의에서 다루는 핵심 주제:
1. **JDBC** — 자바의 데이터베이스 접근 표준
2. **커넥션 풀과 DataSource** — 커넥션 관리의 추상화
3. **트랜잭션** — 데이터 정합성 보장
4. **스프링의 트랜잭션 처리** — 트랜잭션 추상화, 동기화, AOP
5. **예외 처리** — 체크/언체크 예외와 스프링 예외 추상화
6. **JdbcTemplate** — JDBC 반복 코드 제거

## 학습 흐름

```
[JDBC 직접 사용] → 문제 인식 → [스프링이 제공하는 해결책] 적용
```

각 섹션에서 **문제를 먼저 직접 경험**하고, 스프링이 그 문제를 **어떻게 해결**하는지 단계적으로 학습한다. 이런 과정을 통해 스프링이 왜 이런 기능을 제공하는지 깊이 이해할 수 있다.

## 사전 준비

- **Java 17** 이상
- **스프링 부트 3.x**
- **H2 데이터베이스** (개발/테스트용 경량 DB)
- IDE: IntelliJ 권장
