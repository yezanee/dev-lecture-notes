# 섹션 8: 다음으로

## 강의 전체 요약

이 강의에서는 **JDBC부터 시작하여 스프링이 제공하는 데이터 접근 기술**을 단계적으로 학습했다.

### 핵심 학습 내용

| 섹션 | 주제 | 핵심 |
|------|------|------|
| 2 | JDBC 이해 | JDBC 표준 인터페이스, DriverManager, CRUD |
| 3 | 커넥션 풀과 DataSource | 커넥션 풀(HikariCP), DataSource 추상화 |
| 4 | 트랜잭션 이해 | ACID, 커밋/롤백, DB 락, 커넥션을 통한 트랜잭션 유지 |
| 5 | 스프링 트랜잭션 | PlatformTransactionManager → TransactionTemplate → @Transactional |
| 6 | 자바 예외 이해 | 체크/언체크 예외, 런타임 예외 전환, 스택 트레이스 |
| 7 | 예외 처리와 반복 | 스프링 예외 추상화, JdbcTemplate |

### 핵심 원칙: 추상화를 통한 의존성 제거

```
[서비스 계층 — 순수 자바 코드]
     ↓ 의존
[인터페이스 / 추상화]
  ├── DataSource          ← 커넥션 획득 추상화
  ├── PlatformTransactionManager ← 트랜잭션 추상화
  ├── MemberRepository    ← 데이터 접근 추상화
  └── DataAccessException ← 예외 추상화
     ↓ 구현
[구현 기술 (JDBC, JPA, ...)]
```

서비스 계층은 인터페이스에만 의존하므로, **구현 기술이 변경되어도 서비스 코드는 변경할 필요가 없다.**
